# Oracle diagnostic support correction, before locked release

The original development diagnostic adapter incorrectly required both 60-day expert utility and 30-day relative labels for all three oracles. The directional and ranking oracles use 30-day information and should not depend on the 60-day expert label. This is an information-availability defect, identified from source and label support before locked access.

The original 36 diagnostic accounts and the complete frozen development report remain immutable. A separate 36-row diagnostic supplement uses each registered oracle's own information horizon; identical executed targets reuse independently audited original accounts, changed targets run in separate directories under the same native wallet, capital, costs and caps. Unknown future horizons remain explicit cash. Sparse expert support is capped at 0.30 per asset. The oracle is NONCAUSAL/NONDEPLOYABLE, and this supplement never changes causal predictions, candidate selection, ensemble, protocol or economic gate. Locked diagnostics use the corrected support rule before their first execution.

The preregistration hash and all 120 development fits, 24 final fits, 684 causal/readout development accounts, 36 historical oracle accounts and 36 exposure controls are retained.
