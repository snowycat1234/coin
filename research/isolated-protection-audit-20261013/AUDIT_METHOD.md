# Zero-advance postrun audit

- All 11 preregistered guard wallets finished with controller exit code zero; the original control wallets were not rerun or altered.
- The independently prepared baseline identity appendix binds actual executed target arrays, source indexes, quantity profile, frozen scheduler/account, costs, funding convention, and calendar. In particular, 2023 STATIC50 uses the executed e81bf92d target archive, not the earlier 023ebb19 component targets.
- `cold_audit.py` reopens each final lossless pointer and compressed snapshot. The frozen `restore_snapshot` checks SHA-256, shape, dtype, finite values, and row count for every one of 4,020 daily minute chunks. It restores the actual account and protected scheduler from the saved snapshot with `advance_day` deliberately forbidden.
- Each restored financial state hash, completion cursor/stop, full account journals (trades, funding, rejections, breaches, extrema, liquidation and protective events), all executed target rows, and SHA-256 of every one of 37 numeric minute columns must equal the original worker output. The saved result's paid/marked classification is recomputed.
- Four no-trigger cases also reproduce the matched original full-year net PnL, minute drawdown, and paid classification exactly (2023 COMBINED; 2024 VOL_MATCHED, SMA200_10PCT, EXACTHALF). This is a strong no-change control, but it cannot certify true historical venue order acceptance or liquidation behavior.
- Paired paid deltas are shown only when both guard and baseline ended full-year, normally, and flat. A completed marked path with residual exposure has no paid return. The two original 2024 halts were partial, and cannot supply a paired full-year delta.
- The runner reports sampled worker RSS; it was bounded by the launcher but not a kernel-enforced per-process RSS limit. It had a one-CPU and 4 GB address-space rlimit per worker, shared host 8 GB cap checks, zero swap, and a 15 GiB disk reserve. No cgroup memory cap was visible in this environment.
- Only compact outputs and code are in this branch. The full guard day chunks, snapshots, accounts and any original 2025 backup are absent. Their local hashes are recorded in cold-audit receipts, but remote lossless recovery is not claimed.
