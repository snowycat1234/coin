# Native 2023 checkpoint, bit-exact lossless publication candidate

This directory is an independent preservation experiment. It did not advance or rerun any wallet and did not modify the immutable source checkpoint. The source is `../coin_native_half_mix_20261013/STATE_Y2023/recovery`, after the native 2023 process exited successfully and its final checkpoint was audited by the recovery worker.

`y2023_pack/` contains the original final `POINTER.json` and `STATE_000525600.json.gz` byte-for-byte, plus a compressed stream of all genuine day minute chunks and a manifest. `pack.py` preserves float64 bit patterns using per-day exact duplicate-column elimination and a reversible byte-lane shuffle, followed by standard-library XZ compression. It does not approximate floats, drop columns, fit a new model, or regenerate the market/account trajectory. Exact original NPZ files are regenerated solely by deterministic NumPy packaging, verified against each original checkpoint SHA-256.

Run `python pack.py restore y2023_pack NEW_EMPTY_DIRECTORY` in a Python environment with NumPy. Restoration verifies the pack SHA-256, source checkpoint SHA-256, all 365 original NPZ SHA-256 values, row counts, finite float64 arrays, and the final state hash binding. A 2023 round-trip passed all checks, including a byte-for-byte comparison of all 367 restored checkpoint files (365 NPZ days, pointer and snapshot) against the immutable source. The temporary restored directory was deleted after verification; `VERIFY_RESULT.json` records the proof. The test did not call the simulator.

Source day NPZ bytes: 61,253,462. Compressed minute stream: 47,565,952 (22.35% less); entire preservation bundle: 49,648,309 bytes. The account/scheduler snapshot includes native trades, funding, rejections and account state; the original pointer retains complete bindings and 525,600 completed minutes. The native minute result's 37th numeric field is its time coordinate, rebuilt by the original scheduler from the restored 36 float64 values and source time window. The recovery worker separately passed a zero-advance cold restore of the final 2023 scheduler.
