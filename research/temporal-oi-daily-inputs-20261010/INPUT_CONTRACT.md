# CORE5 masked daily OI input contract

Scope: BTCUSDT, ETHUSDT, SOLUSDT, XRPUSDT, DOGEUSDT in that order; every UTC calendar day from 2021-12-01 through 2024-04-30. Inputs only. No price, outcome, model, fit, evaluation or wallet data are required or changed.

- Source: fixed official Binance USD-M daily metrics ZIP and SHA256 CHECKSUM URLs in PLAN.json. Provider ZIP/CSV/checksum hashes and request receipts are retained. Current archive vintage may contain later revisions or backfills.
- Observation clock: parse actual create_time, interpret naive archive labels as UTC, sort chronologically. This convention is not independently certified archive period-end semantics. Unknown original publication remains blank.
- Assumed availability: source day D becomes available at UTC midnight D+2. This deliberately conservative proxy does not prove historical first release or live/as-of eligibility. The final source day has assumed availability 2024-05-02, solely clock metadata.
- Units: sum_open_interest and sum_open_interest_value are original provider fields. Native historical units and value-conversion formula remain uncertified. Do not sum raw quantities across assets or interpret notional changes as price-free positioning.
- Duplicates: remove only byte-identical repeated CSV row bodies. Distinct original bytes at the same parsed timestamp are a conflict even when parsed numeric values are equal. Never choose an arbitrary first/last conflicting row.
- Terminal stock: use only the exact 23:55 labelled record with positive finite quantity and value, matching symbol/day and no conflicting timestamp bytes. Missing/invalid terminal stays blank with mask 0; no prior-row substitution or forward fill. Intraday missing, invalid and conflicting slots are separately retained. A valid terminal does not require all 288 intraday slots.
- Relative quantity change: OI(D)/OI(D-k)-1 for k=1 or 7. Every calendar-day terminal on inclusive interval [D-k,D] must be valid. Missing endpoints or intermediate dates mask the change. First k source days are naturally masked. No return or target field is constructed.
- Consumer CSV: blank numeric value means unknown; validity columns explicitly identify usable archival inputs under this contract. Source day and assumed availability must remain separate. Joining future features must retain all existing price-history/training rows, including pre-December 2021 rows, and mask OI unavailable at the decision clock. This task implements no model/window adapter and makes no prediction or profitability claim.
- Dataset roles: current-vintage retrospective development only; 2023 previously selected and 2024 already seen. No pristine OOS/as-of claim follows.

Acquisition is one sequential GET stream, no HEAD, listing, trading API or mirror. Verified cache objects are never re-downloaded. HTTP 404 is a recorded gap. Transient errors get at most three total attempts per URL across resumptions; exhausted acquisition remains explicitly unresolved/masked. Access denials stop the stream without bypass. Each process runs under the existing bounded cloud guard (one CPU/thread, RSS 2GB, address 4GB, host-used guard 8GB, GPU/swap off, wall 1200s).

Reproduction: in the same repo research directory, run the focused tests using the existing guarded Python entry, ingest each fixed quarter with ingest.py, and package with package_inputs.py. Raw quarter packs contain only new raw ZIP/checksum bodies. Forty-three in-range prior samples refer to the already-published raw45 bundle (SHA256 43718a5239205de9a2fc0f3a93a68cf2991cafb09bc4cefe3106117a6e810358). For standalone consumer inspection, extract the consumer ZIP and import inputs.py; its bundled reused_feasibility/audit.py supports offline normalization. No automatic price-row filtering is provided.
