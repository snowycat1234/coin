目标表字段为 `available_us`、`symbol`、`target_weight`，主键为前两者。只接受完整聚合 bar 已存在的可用时刻；`available_us >= close_us`，其中 `close_us` 是区间终点、不包含在 bar 内。目标权重必须有限、非空。分钟主键重复、负成交金额、无效价格、未对齐时间戳直接拒绝。

## 冻结执行合同

| 项目 | 实现 |
|---|---|
| 执行时刻 | 选 `open_us >= available_us` 的第一分钟，实际事件为 `open_us + 1微秒`；另可加整分钟延迟。严格晚于信号可用时刻。 |
| 价格 | 该分钟 open 的研究代理价，买入加点差/滑点、卖出扣点差/滑点。1微秒表示事件先后，不代表实测网络延迟或保证可成交。 |
| 基准单边成本 | 手续费10bp、半点差1bp、滑点4bp。手续费按实际成交价金额计算；点差/滑点通过成交价格计入 NAV，不再重复扣除。 |
| 压力成本 | 手续费2倍=25bp/边；滑点2倍=19bp/边；两者同时2倍=29bp/边，半点差仍为1bp。 |
| 容量 | 当前订单金额不超过**上一根完整1m** `quote_volume × 0.001`；不使用当前分钟还未结束的成交量。 |
| 部分成交 | 达到容量就缩量，剩余目标重试；最多等待5分钟，过期撤销。零成交不产生费用或收益。 |
| 数据缺口 | 任一交易币缺当前分钟或前一分钟，所有新订单冻结；缺口、后续重试和过期均有记录。日终价格缺失时保留最后已知价格并标记 stale。 |
| 当前交易规格近似 | BTC数量步长0.00001，ETH步长0.0001；数量向下取整；研究最低金额10USDT。不足金额的买单记 `below_min_notional`，卖单记 `dust_unexecuted`；容量不足以满足最低金额则等待下一分钟。 |
| 清仓 | 默认不强平。可选 `liquidate_at_end=True` 在最后可执行分钟提出0权重，仍受容量和交易规格约束，残余持仓不算闭合周期。 |

交易规格来自 `state/instrument_snapshot.json` 的当前 Binance exchangeInfo 快照；实测两币 NOTIONAL 最低额均为5USDT，研究采用更保守的10USDT。**当前快照不是历史交易规则**；进行实盘必须重新查询实际账户费率、当前过滤器与成交条件。合成记账测试显式关闭波动缩放或交易规格，以便精确验证公式，生产调用保留默认合同。

## 共同风险控制

现货无做空、无借贷。输入目标先裁剪到单币30%、合计60%，再用当时已完成的完整 UTC 日收益估计过去30天组合协方差。至少20个有效日收益才允许风险仓位，组合预计年化波动超过10%时等比例缩小。缺失整日及其无法计算的日收益不进入估计。开始评估前应传入热身历史，避免每折重新以无历史状态开始。

成交时卖出先于买入；每笔买单同时受现金、计费后单币上限、合计上限和其他币持仓占比约束。调仓目标额外预留卖买两侧成本，防止第二笔买单的手续费降低 NAV 后，把第一币推过上限。买入后出现负现金或新增风险超限直接报错。

10%是因果估计下的波动目标，不能保证未来实际波动；已有持仓可以因市价上涨或交易受阻而超出目标比例。研究记录持仓比例、缺口冻结和未成交减仓，不虚构在缺口中完成风险减仓。

P02发现官方记录缺失分钟和不标准close，按受影响整UTC日 `valid_day=false` 隔离，聚合和分钟加载均排除该日。**排除该日数据不等于排除持仓损益**：缺口中保留币数和现金，日终先用此前最后已知close记录并标记；恢复数据后使用下一已知价格继续估值或执行，最终跨缺口持仓损益完整计入净值。不能把缺口两端的价格变化删掉，也不能虚构缺口期间的止损成交。

以下字段已加入最终API，基线、候选和压力报告共用：

| 字段 | 含义 |
|---|---|
| `daily_nav.stale_prices` | 日终至少一个行情币使用旧价格。 |
| `daily_nav.stale_exposure` | 日终有实际持仓使用旧价格；现金账户的行情缺口不使现金NAV未知。 |
| `summary.valuation_gap_days` | 日终行情旧价天数，独立于是否尝试订单。 |
| `summary.exposed_valuation_gap_days` | 日终持仓旧价天数。 |
| `summary.daily_risk_observable` | 持仓旧价天数为0；只表示日度估值未因旧价隐藏，不表示可观察所有日内路径。 |
| `summary.drawdown_basis` | 固定 `UTC_daily_observed_NAV`，区分日度观察回撤与真实成交路径极值。 |

`gap_blocks` 仅统计冻结的订单尝试；B1跨缺口持仓且没有下单时它可以为0，所以不能据此断言数据完整。新增整日缺口测试验证：保留持仓、缺口日零估值变动、恢复后完整计入价格下跌；相同两端价格的缺口中可能出现更低价格和更大回撤。因此有 `stale_exposure` 的日度 Sharpe、波动和MDD只能描述记录到的估值，不足以认证风险门槛。即便没有缺口，日度MDD也不覆盖日内或分钟内的极值。

折末清仓和折初0目标受最低金额/容量约束，少量余数持仓可能跨折留存；报告必须披露，不能将清仓目标等同于已全部成交或虚构现金重置。余数没有归零前不算闭合周期。此补充在全量研究和留出评估开始前完成，仅修正数据/记账证据边界，不改变收益参数或用结果调参。
