## 合同

公开主网采集通过同步轻量回调向纸面账户传递真实新鲜报价与瞬时健康。
最多每秒处理一次报价，闭合蜡烛事件立即处理，记录实际报价 ID、实收时刻及处理时刻。
资格缓存超过 45 秒或位于未来时刻即拒绝，健康/磁盘/时钟失败冻结交易。
纸面账户只有 B0/B2 参考，未接入任何获准盈利模型，也不包含币安订单接口。
运行代码、采集、账户、资源守卫和依赖锁的哈希先冻结到 `state/live_contract.json`。
变更后拒绝沿用同一运行版本；账本实现/配置另有独立冻结版本。

`scripts/live.ps1 start/status/stop` 管理隐藏 Windows WSL 前台客户端，
核验 PID、完整命令和创建时刻；停止通过 D 盘 stop 请求触发内部事件，安全关闭数据库。
WSL 前台客户端本身保持发行版存活。旧 `collector.sh start` 已明确拒绝 nohup 启动，
有界 `collector.sh run` 与只读 status 仍可在共享资源限制下使用。

## 资源

实时子 scope 再限制 2 GiB，所有重计算用 `scripts/bounded.sh`。
