# A07 真实资源窗口观察器

2026-10-01；范围：现有公开交易流采集进程的只读资源观察。
工程验收和实际窗口结果以独立新凭证为准；真实 24h 认证尚未完成。

## 需要补齐的证据

冻结质量审计器明确指出原始环真实 24h 峰值和原生辅助库增长尚未认证。
特征 Parquet 的短期 180 天投影不能覆盖原始环、SQLite WAL、进程 CPU/RSS，
更不能替代真实观测窗口。因此新增外部观察器，不改变冻结采集代码或实时数据库。

## 观察合同

- 只选择当前用户拥有的、命令完全匹配的 A07 进程，并要求其处于共享
  `coin-quant.slice`。固定 Linux PID、进程启动 ticks、live 会话和来源合同。
  PID 复用、会话/来源变更、CPU/采集/不可变计数回退都不能拼接窗口。
- CPU 用同一实际进程的累计 CPU ticks 差值，RSS 用实际 `/proc` 计数。
  `VmHWM` 是该进程整个寿命的最高 RSS，并非只属于新窗口，明确另列。
- 读取 live SQLite 的来源、检查点、提交分片计数和 audit head；query_only、
  只读短事务，最长 5 秒，事务在原始环文件扫描前释放。它不替代完整 audit 验证。
- 原始环、DB/WAL/SHM、整个 D 盘 WSL VHD 和共享 RAM 都按实际采样记录。
  原始环扫描不是原子快照；并发退休或缺失的条目计数保留。
  采样最高值不能称为未采样时刻的精确峰值。
  原始环扫描限20,000条目/10秒。预算耗尽的样本明确为未知、保留部分已知字节但
  不作为完整样本，不填零；CPU/RSS/数据库观察继续。终报单列未知样本数量和
  原始环采样完整性，原始环容量须另行核验。
- 默认观察至少实际 86,400 秒，每 300 秒采样；时间从第一个进程快照计起，
  准备/启动时间不缩短窗口。只记录有序、链接哈希的 JSONL，输出总限 10MB。
  若中断或进程更换，保存未验收结果。不会重启采集器、重新建库或补健康时间。
- 启动器仅在新观察器工程验收来源逐项匹配后启动 D 盘 WSL 隐藏进程，
  保存 Windows PID 与创建时间归属，不重复启动已有归属进程。

## 结论边界

工程短测只能授予观察器启动资格。终态的真实 24h 资源采样还须结合冻结质量审计
和资源复核；不会自动勾选清单第 56 项，也不会授予 14/30 天建模、alpha、
健康天数、候选前向或任意故障下的 180 天存储保证。
