# A07 特征分布与数值范围诊断

2026-10-01；范围：真实采集数据的只读描述性 QA，工程验收结果另见新凭证。

## 实现与边界

新诊断在独立分析进程中加载已冻结的质量审计器，继承其双币同秒配对规则，
只观察父类已经确认可用的秒。断档、不确定成交序号区间、陈旧报价及无有效 mid
保持原排除规则。原采集器、数据库、首份正式质量报告和既有研究不改写。

17 项特征按币种与 UTC 小时保存有限值数量、合法空值数量、非零数量、均值、
总体标准差、最小值和最大值。采用 Welford 增量统计，不累计全部行或计算分位数；
最多保留两条待配对特征行、1,440 个币种/小时分组，沿用有界 Arrow 批次。
空值不填零。状态或均值的求和只是数值汇总，不解释为实际成交总量。

价差、数量、成交额与计数检查非负；mid/VWAP 检查正值；盘口/成交不平衡
检查 [-1,1]（允许固定浮点容差）；价格改变次数不得超过报价更新次数。
报警保留原值，不能通过删除异常值改善质量。任何原完整性审计失败时，不输出
部分特征统计作为已通过结果。没有未来标签、模型拟合、收益或交易资格计算。
