# P02：全量历史数据与冻结验收

验收日期：2026-09-30。状态：通过；异常数据显式隔离。

## 数据合同

BTCUSDT、ETHUSDT 现货 1m，2022-01 至 2026-08，共 112 个月档。
来源为 Binance 官方公开月档，逐档核验官方 SHA-256 与 ZIP CRC。
保留原始 ZIP、校验文件、接收时间、原始收盘时间以及标准化文件哈希。
内部时刻统一为 UTC 微秒，标准 bar 收盘为右开边界。
2025 年之前的毫秒和之后的微秒分别识别，拒绝档内混合单位、重复、错误开盘对齐和非法 OHLCV。

异常日期整个 UTC 日标 `valid_day=false`。研究分钟输入和聚合输入均排除该日，
原始记录保留，未用插值或造价补齐。聚合窗口只接受完整分钟和正确边界。
`excluded_windows` 计数针对实际存在的窗口；完全不存在的窗口没有分组，
因此验收总缺失窗口须按日历期望数与最终行数比较，每币实际少 96 个 15m／24 个 1h 窗口。

持仓跨隔离日不能丢弃跨期损益：以最后已知价格标记陈旧估值，恢复行情后完整计入变动。
未知日内路径不得用于认证回撤上限；该限制由 P03/P04 的风险可观察性字段传递。

## 冻结与留出

数据版本：`dcfd7fdb5824325da2e9acbc4426570e5a26b31260891f5569ae5651f1b11336`。
`state/dataset_lock.json` 冻结 112 个标准化分钟文件、4 个聚合文件、质量报告和数据政策哈希。
研究运行前逐个验证，任一变化即拒绝执行，不能在结果揭晓后替换数据。

2026-03-01 至 2026-09-01 是最后六个月留出，仅进行格式／质量核验，未查看策略表现。
收益计算、模型选择和外层 OOS 均先过滤该区间。

## 运行边界

所有下载、清洗、环境和缓存在 D 盘。全量下载预留每档 12 MB，清洗预留 1.5 GB，
16 GB 预警、18 GB 停止新增、20 GB 硬限，包含整个现有 D 盘 WSL 虚拟磁盘。
未使用 C 盘保存项目数据。重复构建只能发生于新的登记数据版本，禁止改写当前冻结研究输入。
