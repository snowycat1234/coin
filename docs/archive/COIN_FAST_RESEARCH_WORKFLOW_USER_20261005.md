## 1. 先确定真正慢在哪里，不猜测模型或硬件

用户观察单轮约25分钟，但实验很短。公开D079记录的内部主体79.41秒、外层命令113.98秒，内部计时还包含容量扫描等工作；独立金融/目标/门槛的内部计算分别约0.27/0.55/0.22秒。最后一个已归档核验结束到staged gate约7分42秒。它们不是完整Codex会话剖析，不能把未记录间隔全部叫作模型思考或无用等待。

先复用最近2—3轮现有task、receipt与命令记录，能读到必要会话计时就只读本任务的耗时/usage元数据；不可访问则UNKNOWN，不遍历或导出其他会话、密钥或私密内容。不为补齐计时重跑全部历史。

在现有记录上增加轻量阶段字段，区分：
- 上下文定位与计划、实现修改；
- 环境/导入/进程启动、数据/哈希/容量检查；
- 实际实验、测试与独立核验；
- 子agent等待/失败重做；

用单调时钟记录区间；并行任务按区间并集统计墙钟，不把各耗时相加。父任务包含的子任务不能重复计算，内部计时不能冒充命令或端到端耗时。记录实际可见的模型/推理配置，未知则未知，不先认定是模型太慢。只需几处计时与一条摘要，不建新监控平台。

## 2. 压缩上下文和收尾，这是默认优先改进

当前AGENTS混有多代已覆盖指令和逐版状态；收尾脚本会把同一summary写入README、RESEARCH_STATUS、GOALS、PROGRESS、FAST_RESEARCH_TASK_CHECKLIST、MULTI_ASSET记录、DECISION_LOG和AGENTS。停止这种新增重复。

收拢为：
- AGENTS：仅保留当前有效权限、安全边界、常用入口、验证与交付原则；不是进展年表。
- RESEARCH_STATUS：当前研究主力/挑战者、关键限制、正在做什么、下一决策及结果入口；替换过时的“当前状态”，旧版留在Git/已有历史。

## 3. 实验循环与发布循环分开，不把每个小诊断都变成项目

一个相关经济问题可包含：已保存数据诊断、一个明确挑战者、必要回归、完整对照和决定。允许在同一有限模块内完成，再统一收尾、按既有授权正常提交推送；每个实验仍独立登记，不依赖提交次数计试验数。

只读诊断应直接读取旧账本，不重放市场、不复制行情。不改经济行为的整理不需要重新做策略选择；已改变信号/仓位/费用/执行的实验则完整重跑受影响账户，不能通过编辑旧结果替代。

开始前简记假设、对照、数据角色、主要经济指标、预算和停止条件。看过结果才提出的后续实验按当时真实时间另登记，不能伪称事前预注册。到停止条件自主采用、保留、暂停或换路，不等待普通研发批准，也不无限搜索。

复用正常runner与参考检查器，将新配方写入小配置；实际有新语义才改代码。已有收尾流程抽出最小可复用部分，用真实结果生成摘要和manifest，不再每轮写一个硬编码D编号、日期、任务ID和“预期亏损/盈利”的专用close脚本。工程正确性检查不能要求收益必须正或必须负才能完成。

一条批处理命令可以顺序完成必要阶段，并为各阶段保存真实退出码。这样减少模型与工具之间的等待，不等于忽略失败、假称未运行的检查通过或无限后台运行。

## 4. 按改动风险选择验证，优先自动检查，不默认开多个agent

区分以下情形，不设每轮相同的大清单：

A. 只读诊断/报告：检查输入身份、计算和引用；复用有效旧市场证据，不跑完整账户回归。
B. 已有引擎上的新配方：必要的目标因果/方向/资产顺序检查、实际完整账户、已有独立金融与风险核验。
C. 账户、费用、订单、风控、数据可得性变化：相关反例、旧默认小型golden对照、受影响路径集成测试及独立复核。必要时升级更完整验收。

每次新账本的低成本资金守恒、费用符号、多空仓位、时间因果和完整资本核对继续执行。几百毫秒的金融核验不值得删除；要减少的是重新设计核验和重复讲解，不是降低金融正确性。

只有代码/相关依赖、配置、输入、环境和检查范围等身份支持时才能复用证据；仅文件名、mtime或“上次绿了”不够。复用标REUSED并绑定凭证，未执行写NOT_RUN；依赖未知或行为改变则重验。独立参考不能通过直接调用被测函数生成期望值来自证。

默认一个主agent直接处理短任务，真正需要独立代码审阅时再委派一个范围明确的只读reviewer。可并行做无共享写入的独立工作；不让多个agent重复读仓库、写同一文件、重复启动同一账户。短脚本交给工具执行，不为亚秒核验另开模型会话。

子agent先确认必要权限；失败后只接管其未完成部分，复用有效输出，不扩大权限、不重做完成工作。审阅明确修改范围、重点风险、输入工件及完成条件；通常一次批量发现、一次针对性复核，真实重大新问题仍须处理，不能限时强制判通过。

不擅自改用户全局模型或降低关键审计能力；先减少不必要的模型调用、长输出和任务往返。没有权限修改推理配置就只报告实际情况。
